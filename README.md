# Ладно · сольфеджио на гитаре

Статический самоучитель на русском: 14 глав от нот и интервалов до пентатоники, блюза, слуха, ритма и чтения с листа. Построен на основе проекта [BaikovaAlina/ladno](https://github.com/BaikovaAlina/ladno), без фреймворка и сборщика.

## Запуск

ES-модули загружаются браузером по HTTP: из папки проекта выполните

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000/`. Установка зависимостей и сборка не нужны. **Прямое открытие `index.html` через `file://` в большинстве браузеров блокирует относительные импорты ES-модулей из-за политики безопасности.** Используйте локальный сервер или статический хостинг (например, GitHub Pages); при отключённой сети локальный сервер по-прежнему работает.

VexFlow 4.2.2 и Tone.js 14.8.49 подключаются через CDN. Если они недоступны, нотный стан рисуется встроенным SVG, а звук синтезируется через Web Audio API. Синтезатор начинает работу только после действия пользователя. Метроном использует `Tone.Transport`, а без Tone.js — таймер браузера. Копирование в буфер обмена зависит от разрешений и защищённого контекста браузера.

## Содержание

- 01–08: ноты, интервалы и их обращения, трезвучия, септаккорды, гаммы и лады, квинтовый круг и аккорды тональности, гармонические прогрессии и композиция. Наброски можно сохранить и скачать в JSON.
- 09–10: минорная и мажорная пентатоники, пять гитарных боксов, минорный и мажорный блюз, 12-тактовый квадрат и упражнения. Формы, пересекающие границы отображаемых 0–15 ладов, показаны частично.
- 11–12: тренажёры всех 12 интервалов и девяти видов аккордов, настройки звучания, обратная связь и статистика.
- 13–14: ритмическая сетка, метроном, синтезированные ударные, простукивание, определение размера и 30-секундное чтение нот с листа.

Тема, открытые главы, статистика и мотивы сохраняются локально в `localStorage` под ключом `ladno.progress.v2`. Кнопка сброса очищает прогресс и статистику, сохраняя выбранную тему. Данные никуда не отправляются.

## Устройство

```text
index.html               разметка и 14 разделов
style.css                темы, адаптивная сетка и анимации
app.js                   навигация и визуализаторы
 data/notes.js           ноты, струны, MIDI и позиции
 data/intervals.js       интервалы, обращения и пресеты слуха
 data/chords.js          аккорды, обращения, поиск аппликатур
 data/scales.js          гаммы, позиции, боксы и блюзовые ноты
 data/progressions.js    тональности, прогрессии, ритмы и размеры
 ui/state.js             версионированное хранение, серии, экспорт текста
 ui/fretboard.js         общий интерактивный SVG-гриф
 ui/staff.js             VexFlow и резервный SVG-стан
 ui/earTrainer.js        аудио и слуховые тренажёры
 ui/exercises.js         упражнения, ритм и чтение с листа
 tests/data.test.mjs     проверки музыкальных данных (Node.js)
```

Нота описывается именем, MIDI-высотой и классом высоты; позиция на грифе — `{string, fret, midi, pc, key}`. Интервал содержит полутоны, диатонические шаги и ссылку на обращение. Аккорд и гамма задаются массивами полутоновых смещений и буквенных шагов; блюзовая ступень у гаммы задаётся `blueNoteOffset`. Позиционный бокс содержит диапазон ладов, список позиций, пальцы и `bluePositions`. Прогрессия хранит последовательность ступеней и подсказку по мелодическому движению.

Запуск проверок данных:

```sh
node tests/data.test.mjs
```

## Публикация в отдельном репозитории

Создайте пустой репозиторий `ladno-solfeggio` в GitHub, затем в отдельной копии файлов проекта (без каталога `.git` исходного проекта) выполните:

```sh
git init -b main
git add .
git commit -m "Создать учебник Ладно Сольфеджио"
git remote add origin https://github.com/ВАШЕ-ИМЯ/ladno-solfeggio.git
git push -u origin main
```

После этого можно включить GitHub Pages из ветки `main`, корневой каталог. Используйте своё имя и адрес репозитория вместо примера.
