# Ладно. Сольфеджио

Самоучитель теории музыки для гитаристов-новичков: **14 разделов**, интерактивный гриф,
нотный стан, два слуховых тренажёра, ритм с метрономом и ударными, чтение с листа
и композиция с экспортом в JSON.

Чистый HTML/CSS/JS (ES-модули), без сборки и зависимостей. VexFlow и Tone.js
подключаются с CDN как **усилители**: если CDN недоступен, работают собственный
SVG-стан и синтезатор на Web Audio.

---

## Как открыть

```bash
# Быстрый способ: локальный сервер (рекомендуется)
python3 -m http.server 8000
# затем http://localhost:8000
```

> **Важно про `file://`.** ES-модули (`<script type="module">`) браузеры
> не загружают с локального диска: `index.html`, открытый двойным щелчком,
> покажет пустые разделы. Поэтому нужен любой статический сервер — `python3 -m
> http.server`, `npx serve`, GitHub Pages, Netlify. Для GitHub Pages достаточно
> залить содержимое папки, ничего собирать не нужно.

Проверить данные без браузера:

```bash
npm install                   # jsdom + esbuild, только для проверок
node tools/check-data.mjs     # проверка музыкальных данных (интервалы, гаммы, боксы, аккорды)
node tools/smoke.mjs          # смоук-тест в jsdom: все 14 разделов и ключевые кнопки
```

Сайту для работы npm **не нужен**: `package.json` существует только ради двух
скриптов проверки и необязательной однофайловой сборки.

### Если очень нужно открыть без сервера

```bash
npm run build:single          # создаст ladno-single.html (~470 КБ)
```

Это один HTML-файл, в который вшиты CSS и все модули (через esbuild). Его можно
отправить письом, открыть двойным щелчком с диска или положить на флешку.
VexFlow и Tone.js остаются внешними CDN-скриптами и подключаются асинхронно:
без интернета сайт работает на собственном SVG-стане и Web Audio.
Обычная версия (`index.html`) при этом не меняется и по-прежнему собирается
без сборки.

## Схема данных

### Ноты и гриф

Высота — целое MIDI (`C4 = 60`), класс высоты — `midi % 12`. Имя ноты хранится
отдельно: `C♯` и `D♭` звучат одинаково, но обозначают разные ступени.

```js
// core/notes.js
STRINGS = [
  { name: "e", midi: 64, number: 1 },   // 1-я струна — тонкая, рисуется сверху
  … { name: "E", midi: 40, number: 6 },
];

parseNote("Bbb")   // → { letter:"B", accidental:"bb", alteration:-2, pc:9 }
spellInterval("C", 4, 2)  // → "E"  (большая терция — это E, а не F)
writtenNote("F#", 66)     // → "F♯4"
positionsForMidi(64)      // → [{ string:0, fret:0, midi:64, key:"0:0" }, …]
```

### Интервалы

```js
{
  id: "M3",            // стабильный ключ (используется в localStorage)
  short: "б.3",        // подпись на кнопке
  name: "Большая терция",
  semitones: 4,        // полутоны
  steps: 2,            // сколько букв пройти — для правильной записи
  character: "…",      // как звучит словами
  feel: "светло",      // мягко | резко | пусто | напряжённо
  consonant: true,
  tip: "…",            // блок «На пальцах» с конкретными струнами
  mistake: "…",        // блок «Типичная ошибка новичка»
}
```

### Трезвучия и септаккорды

```js
{
  id: "half", name: "Полууменьшённый", symbol: "m7♭5",
  offsets: [0, 3, 6, 10],  // полутоны от корня
  steps:   [0, 2, 4, 6],   // буквенные шаги для записи
  description, tip, mistake,
}
```

Обращения и аппликатуры **не хранятся**, а вычисляются:

```js
makeChord("G", getSeventh("dom7"), 2)        // 2-е обращение: квинта в басу
chordInversionsVoicings("C", getTriad("major"))  // все обращения + лучшая аппликатура
voicingsOnString("Am7", getSeventh("m7"), 4)     // аппликатуры с басом на 5-й струне
```

`findVoicings()` перебирает реальные позиции на грифе, требует одну ноту на струну,
нижний голос на толстой струне, и сортирует варианты по «удобству» (охват ладов,
ширина по струнам, открытые струны).

### Гаммы и боксы

```js
{
  id: "minorPent", name: "Минорная пентатоника", family: "pentatonic",
  offsets: [0, 3, 5, 7, 10],       // полутоны от тоники
  steps:   [0, 2, 3, 4, 6],        // буквенные шаги
  formula: "1½Т – Т – Т – 1½Т – Т",
  degrees: ["1", "♭3", "4", "5", "♭7"],
  description, plain, mistake, sound,
}
```

Боксы пентатоники (общие для минорной и мажорной) задаются **окном в ладах**:

```js
pentatonicBoxes(9, "minor")  // A → тоника на 6-й струне, 5-й лад
// [ { id:1, start:5, end:8 }, { id:2, start:8, end:11 }, … ]
// { from, to } — это и есть полупрозрачная область на грифе
```

Обычные гаммы получают три позиции автоматически — по корню на 6-й, 5-й и 4-й
струнах: `scalePositions(rootPc, scale, 3)`.

### Блюзовые гаммы

Блюзовая нота описана **смещением от тоники**, а не отдельным списком:

```js
BLUES_TYPES = [
  { id:"minor", scaleId:"minorBlues", blueOffset: 6 },  // ♭5 — между 4 и 5
  { id:"major", scaleId:"majorBlues", blueOffset: 3 },  // ♭3 — между 2 и 3
];
```

На грифе это отдельный цвет (`kind: "blue"` → CSS-переменная `--fb-blue`).

### Прогрессии

```js
{
  id: "1645", name: "I – vi – IV – V", title: "Сороковые",
  degrees: [0, 5, 3, 4],           // ступени мажора
  minorDegrees: null,              // вариант для минора (если есть)
  meter: "4/4", beatsPerChord: 4,
  character, melodyTips: [...], example, origin,
}
```

### Ритм

```js
// паттерн: времена в долях, а не в секундах
{
  id: "syncopation", name: "Синкопа", meter: "4/4",
  hits: [ { start:0, dur:1, voice:"kick" }, { start:0.5, dur:0.5, voice:"snare", accent:true }, … ],
  description, plain, mistake,
}
```

### Прогресс в localStorage

Один ключ — **`ladno.progress.v2`**, внутри поле `version: 2`. При загрузке объект
всегда проходит через `normaliseProgress()`: неизвестные/битые поля заменяются
значениями по умолчанию, поэтому старая схема не ломает приложение.
Данные первого проекта (`ladno-progress-v1`) автоматически мигрируют.

```js
{
  version: 2,
  streak: 7, bestStreak: 19, correct: 64, mistakes: 21,
  exercises: {           // простые упражнения: правильные/ошибки/серии
    "notes":        { correct: 12, mistakes: 3, streak: 2, bestStreak: 8 },
    "pentatonicBox":{ … },
  },
  earIntervals: {        // тренажёр 11: интервал → режим → счётчики
    "M3": { up: { correct: 9, mistakes: 2 }, down: { … }, harm: {…}, round: {…} },
  },
  earChords: {           // тренажёр 12: тип аккорда → счётчики
    "dom7": { correct: 5, mistakes: 1 },
  },
  course: { visited: { notes: true, … }, last: "pentatonic", completed: {} },
  rhythm: { records: {}, bestBpm: 0 },
  notation: { best: 17, attempts: 3, correct: 41, total: 52 },
  composition: { motifs: [ { id, title, root, scaleId, rhythmId, notes: [...], chordSymbols } ] },
  settings: { theme: "light", instrument: "guitar", bpm: 90, soundOn: true },
}
```

Статистика не отправляется никуда и не переносится между браузерами. Кнопка
**«Сбросить весь прогресс»** в подвале очищает ключ полностью.

## Единый рендер грифа

Все разделы рисуют гриф одной функцией — поэтому подсветка, клики и тема
работают одинаково:

```js
renderFretboard({
  container,        // элемент или id
  highlighted,      // ["2:3", { string, fret, kind: "root" | "note" | "blue", label }]
  root,             // класс высоты тоники — альтернатива kind: "root"
  rootPositions,    // явные позиции корня
  boxes,            // [{ from: 5, to: 8, label: "Бокс 1" }] — полупрозрачные области
  selected,         // Set выбранных позиций "струна:лад"
  names,            // { 0: "C", 1: "C#" } — правильные имена вместо стандартных
  clickable,        // кликабельные <g role="button" tabindex="0">
  onNoteClick,      // (position) => …
  showAll,          // показывать все ноты или только подсвеченные
  hideLabels,       // упражнения «найди ноту»: точки есть, подписей нет
  questionKey,      // позиция-вопрос: рисуется «?»
  fromFret, toFret, // окно ладов (для упражнений «в позиции N»)
  status,           // id элемента для подписи нажатой ноты
  colors,           // переопределение цветов
});
```

Цвета берутся из CSS-переменных (`--fb-root`, `--fb-note`, `--fb-blue`, …),
поэтому **переключение темы перекрашивает SVG без перерисовки**.

Геометрия тоже проверена глазами и тестами: нота стоит в середине клетки между
порожками (а не на линии), открытая струна — слева от порожка, 12-й лад не
уезжает за край `viewBox`, точки-инлей лежат между струнами, а не под нотами.
Подписи боксов рисуются внутри рамки снизу и не закрывают ноты.

Стан (`ui/staff.js`) подгоняет размер по `fitStaff()`: короткий пример из одной
двух нот больше не растягивается на всю ширину в огромную картинку. Если
VexFlow с CDN недоступен, включается собственный SVG-стан — со скрипичным
ключом, нарисованным контуром (символ `𝄞` есть не в каждом системном шрифте,
поэтому запасной вариант рисует ключ путями, а не текстом).

## UX-решения

- **Звук только по клику.** Никакого autoplay: Tone.js инициализируется на первое
  действие пользователя (`pointerdown`/`keydown`), каждая нота и гамма звучит
  после кнопки. Это требование браузеров и правило проекта.
- **Единый компонент «тренажёр»** (`ui/trainer.js`): настройки → сессия →
  фидбек → статистика. Разделы 11 и 12 добавляют только генерацию вопросов.
- **Тёмная тема** — атрибут `data-theme="dark"` на `<html>`, сохраняется в
  `settings.theme`. Все цвета — переменные, включая палитру SVG-грифа.
- **Хлебные крошки и прогресс курса** — какие разделы открыты, хранится в
  `course.visited`; полоса в сайдбаре показывает `N / 14`.
- **«Поделиться результатом»** — копирует в буфер обмена текст вида
  «Моя серия в интервалах: 17 подряд!», с запасным вариантом для браузеров
  без Clipboard API.
- **Мобильный вид** — горизонтальный скролл грифа с `-webkit-overflow-scrolling:
  touch`, крупные кнопки ответов (44+ px), `env(safe-area-inset-*)` для подвала
  и нижних плашек, навигация превращается в прокручиваемую строку.
- **Микроанимации** — зелёная «волна» правильного ответа, встряхивание при
  ошибке, плавное появление заданий; при `prefers-reduced-motion` всё отключается.
- **Горячие клавиши** — `T` переключает тему, `Пробел` в разделе ритма делает хлопок.

## Как добавить новое

**Гамму** — объект в `SCALES` (`core/scales.js`): `id`, `name`, `family`,
`offsets`, `steps`, `formula`, `degrees`, `description`, `plain`, `mistake`.
Она сразу появится в селектах разделов 05, 01 и 08.

**Аккорд** — объект в `TRIADS` или `SEVENTHS` (`core/chords.js`) с `offsets` и
`steps`. Обращения и аппликатуры найдутся сами.

**Интервал** — объект в `INTERVALS`; он автоматически попадёт в тренажёр 11
и в кнопку «наборы».

**Прогрессию** — объект в `PROGRESSIONS` с `degrees` (и при необходимости
`minorDegrees`) и `melodyTips`.

**Раздел** — новый модуль в `ui/sections/`, `registerSection(id, { mount, onShow })`
в `app.js`, пустой `<section>` в `index.html` и ссылка в навигации.

## Об источниках теории

Формулировки и объяснения — авторские, простым языком, но опираются на
классическую традицию: Вахромеев и Способин (интервалы, аккорды, лады),
Фридкин (сольфеджио и чтение с листа), Троицкий и Молотков (гитарная
аппликатура). Все примеры привязаны к грифу: конкретная струна и лад,
а не абстрактная схема.
