# Ладно · Фортепиано 🎹

Интерактивный курс и тренажёр фортепиано от самых первых нот до продвинутой джазовой гармонии, чтения нот с листа, тренировки музыкального слуха, ритмики и отчётов об ошибках в Telegram-бот.

Проект выполнен в тёплом редакционном дизайне оригинального учебника [«Ладно»](https://github.com/BaikovaAlina/ladno).

---

## ✦ Особенности проекта

1. **Реалистичная интерактивная клавиатура фортепиано**
   - 3–4 октавы с белыми клавишами из слоновой кости и эбеновыми чёрными клавишами.
   - Поддержка кликов мыши, мультитача на смартфонах и планшетах.
   - Игра с клавиатуры компьютера (раскладка `A-W-S-E-D-F...` для белых и чёрных клавиш).
   - Переключение подписей: ноты слогами («До Ре Ми»), буквами («C D E») или чистые клавиши.
   - Отображение правильных номеров пальцев (аппликатуры 1–5).

2. **Двойной нотный стан Grand Staff (SVG)**
   - Настоящая акколада, объединяющая скрипичный (𝄞) и басовый (𝄢) ключи.
   - Центральное До (C4) на добавочной линейке как мост между руками.
   - Динамическое отображение играемых нот в реальном времени.
   - Автоматический расчёт добавочных линеек и знаков альтерации (диез ♯ / бемоль ♭).

3. **Акустический синтезатор фортепиано**
   - Полифонический движок на базе **Web Audio API** с поддержкой **Tone.js**.
   - Натуральная огибающая удара войлочного молоточка рояля (быстрая атака, спад, гармонические обертоны).
   - Выбор тембров: *Концертный рояль*, *Тёплое кабинетное пианино*, *Rhodes / Электропианино*.
   - Работает полностью автономно в любом современном браузере без установки пакетов.

4. **Интерактивный метроном и тап-тренажёр ритма**
   - Точный аудио-метроном с регулировкой BPM (40–220) и акцентом на первую долю.
   - Размеры 4/4, 3/4 (вальс), 2/4 (марш), 6/8.
   - Измерение точности каждого тапа с точностью до миллисекунды (±мс), оценка попадания в долю («Идеально», «Отлично», «Раньше», «Позже») и зачётный режим на 10 тапов.

5. **Прямая интеграция с Telegram-ботом**
   - Токен бота: `9194715215:AAE7Tly-kvnSCpzHL7zb12mZkM1uiXZkEJY`.
   - **Автоопределение Chat ID в 1 клик** через Telegram Bot API (`getUpdates`).
-  - **Отчёты о выполненных упражнениях**: бот получает сообщения о каждом успешно пройденном задании (какое упражнение выполнялось, что было сделано, текущая серия).
+  - **Подробный разбор ошибок**: бот получает сообщение с точным указанием вопроса, неверного ответа, правильного ответа и понятного музыкального совета.
   - Уведомления о рекордных сериях (5, 10, 20 правильных ответов подряд).
   - Итоговая сводка тренировки по запросу ученика.

## 🚀 Запуск и использование

Сайт полностью статичен. Никаких сборщиков, Node.js или внешних серверов не требуется.

### Локальный запуск
Просто откройте `index.html` в браузере (Chrome, Safari, Firefox, Edge).
Либо запустите локальный сервер:
```bash
python3 -m http.server 3000
```
И откройте в браузере `http://localhost:3000`.

### Размещение на GitHub Pages
1. В репозитории откройте **Settings → Pages**.
2. В секции **Branch** выберите `main` (или вашу рабочую ветку) и папку `/ (root)`.
3. Нажмите **Save**. Через минуту сайт будет доступен по адресу `https://baikovaalina.github.io/ladno-piano/`.

---

## ✈ Настройка Telegram-бота

1. Откройте в Telegram вашего бота (или перейдите по ссылке из 10-го раздела сайта).
2. Нажмите кнопку **«Запустить» (`/start`)** или отправьте любое сообщение боту.
3. В разделе **10 / Telegram-бот** на сайте нажмите **«Определить ID ↻»**.
4. Сайт автоматически обнаружит ваш чат и пришлёт подтверждение!
5. По желанию нажмите кнопку **«Отправить тест ✈»** для проверки.
