# Ладно — фортепиано с нуля

Самостоятельный интерактивный курс в спокойном оформлении проекта «Ладно». Он ведёт от знакомства с клавиатурой к нотному чтению, слуху, аккордам, ритму, памяти и самостоятельной музыкальной работе.

## Что уже работает

- **Курс из 8 уроков:** первые клавиши, пульс и длительности, нотный стан, слух, аккорды и обращения, гаммы и координация, сложный ритм, гармония и репертуар. Темы доступны без блокировок; лучше проходить их по порядку.
- **Ноты с листа:** случайная нота или короткая мелодия на нотном стане; ответ — на виртуальном пианино, MIDI-клавиатуре или клавишах компьютера.
- **Слух:** упражнения на интервалы, окраску аккорда и распознавание высоты ноты.
- **Аккорды:** собери трезвучие или септаккорд на клавиатуре и послушай результат.
- **Ритм:** послушай рисунок, повтори его в такт метронома и посмотри на точность.
- **Музыкальная память:** послушай последовательность звуков и сыграй её по порядку.
- **Прогресс на устройстве:** попытки, правильные ответы, серия и отметки об уроках сохраняются в браузере. Они не отправляются на сервер.
- **Telegram — по желанию:** только после настройки личного Node.js-сервера и явного включения отчётов в приложении. Бот получает результат проверенного упражнения и краткие детали ошибки.
- Звук генерируется самим браузером; библиотеки и сборка не нужны. MIDI доступен в браузерах с Web MIDI API (обычно Chrome/Edge; для удалённого сайта нужен HTTPS).

## Запуск для практики

Нужен Node.js 18 или новее. Из каталога проекта:

```bash
npm start
```

Открой `http://localhost:4173`. Зависимости устанавливать не надо. Для тестирования API открой также `/api/status`; без Telegram-настроек интерактивные упражнения всё равно работают.

Можно открыть `index.html` напрямую или разместить статические файлы на GitHub Pages: упражнения, звук и локальный прогресс будут работать. Для Telegram обязательно нужен Node.js-сервер — GitHub Pages не запускает серверный код.

## Подключение личного Telegram-бота

> **Безопасность:** токен, который уже публиковали в переписке, репозитории или скриншоте, нужно отозвать. Выпусти новый токен у `@BotFather`; не используй опубликованный. Не присылай новый токен в чат, не вставляй его в `app.js` и не коммить `.env`.

1. Создай бота через `@BotFather` и выпусти **новый** токен.
2. Скопируй `.env.example` в `.env` и открой файл только у себя на компьютере:

   ```bash
   cp .env.example .env
   ```

   Впиши токен в `TELEGRAM_BOT_TOKEN` и придумай отдельный длинный пароль (минимум 12 символов) для `APP_PASSWORD`. Настоящий `.env` исключён из Git.
3. Напиши своему новому боту `/start`. Затем, пока сервер не запущен и у бота нет активного webhook, из каталога `piano` выполни:

   ```bash
   npm run telegram:link
   ```

   Скрипт безопасно найдёт личный chat ID и запишет его в `.env`; токен в терминал не выводится. Если у бота уже настроен webhook, возьми личный chat ID через собственную инфраструктуру бота и запиши его в `TELEGRAM_CHAT_ID` вручную.
4. Запусти или перезапусти `npm start`. В приложении открой **«Уведомления в Telegram»**, введи `APP_PASSWORD` и включи переключатель отчётов.
5. После каждого ответа, который проверяет приложение, бот отправит название упражнения, результат и — при ошибке — ожидаемый ответ и краткую подсказку. Переключатель можно выключить в любой момент.

Переменные окружения хостинга называются так же: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `APP_PASSWORD`. В публичном размещении используй HTTPS, не публикуй `.env` и не отключай пароль. Не помещай секреты в GitHub Pages, HTML, JavaScript или GitHub Actions-логи.

## Приватность и ограничения

- Клавиши, ответы, серия и история остаются в `localStorage` текущего браузера.
- Сервер Telegram получает только выбранный тип упражнения, верный/неверный результат и краткие поля ответа; отправка выключена по умолчанию и требует входа.
- Сервер ограничивает размер запросов и частоту сообщений. Пароль обязателен для отправки уведомлений, а сессия хранится только в памяти сервера.
- Проект не содержит реального токена и не отправляет данные, пока пользователь сам не настроит и не включит уведомления.
- Виртуальные клавиши и Web Audio доступны и без MIDI-инструмента. Если браузер не поддерживает MIDI или звук, основные задания всё равно можно проходить.
